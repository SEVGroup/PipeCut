# PipeCut 0.1 — macOS

Экспериментальный нативный конструктор одной круглой трубы на другой. SwiftUI + SceneKit, macOS 14+, без внешних библиотек. Репозиторий SEVGroup/PipeCut проверен через GitHub API: `private: true`, `visibility: private` 22 октября 2026. Видимость не изменялась, GitHub Release не создавался.

## Запуск и сборка

Готовый архив PipeCut-0.1-macOS.zip содержит PipeCut.app для Apple Silicon. Распакуйте и откройте приложение. Подпись локальная ad-hoc, нотариального заверения Apple нет. Для другого Mac предпочтительно собрать из исходников (Xcode с Swift 6):

```sh
./scripts/build-app.sh
open dist/PipeCut.app
```

Скрипт запускает тесты, собирает release, формирует .app и zip. Собирает для архитектуры текущего Mac; universal binary не заявлен. При системном предупреждении используйте обычный диалог macOS «Открыть», только если доверяете исходникам. Не отключайте защиту системы.

## Интерфейс Dark Workshop

Графитовая рабочая область с оранжевым контуром стыка. Крупная 3D-модель слева, параметры справа, обе развёртки одновременно в нижней части окна. Слева — панель видов, сброса камеры, сетки и видимости линий. В нижней части 3D переключаются перспектива, вид спереди и сверху. Выбранная камера сохраняется при изменении видимости линий.

Расчёт обновляется при изменении числовых значений. В блоке «Экспорт шаблонов» выберите PDF 1:1 или DXF, затем нужный шаблон в меню. Чертежи на экране оформлены для тёмного фона; экспортный PDF остаётся чёрно-белым. 3D показывает полые стенки и торцы; отверстие основной трубы пока не вычитается, наружный стык выделен оранжевым.

## Что работает

- Наружные диаметры и обе толщины в мм, угол 30–90°, поперечное смещение осей, осевой отступ ответвления 0–20 мм.
- Проверка d ≤ D, положительных толщин и поддерживаемой топологии до расчёта.
- Аналитическое пересечение наружных цилиндров, отдельные справочные пересечения со стенками.
- Вращение и масштабирование 3D мышью; угол меняется также ползунком. Ответвление обрезано по ближней наружной поверхности плюс осевой отступ. Основная труба показана с непрозрачными стенками, отверстие в 3D не вычитается.
- Развёртка наружной поверхности ответвления и контур отверстия на наружной поверхности основной трубы.
- Независимая видимость реза, справочных линий стенок, осевых, калибра 100 мм, четырёх меток совмещения.
- PDF одной выбранной развёртки: произвольная страница по габаритам, 1 мм = 72/25.4 pt. DXF ASCII AC1015, LWPOLYLINE, $INSUNITS=4 (мм), отдельные слои.

Обе развёртки видны одновременно. Выберите нужный шаблон в меню формата экспорта; для второго повторите экспорт. Видимость слоёв влияет на оба формата. PDF печатать строго 100%, без «вписать», сверив калибр линейкой. Масштаб экранного просмотра произвольный. Метки — четверти окружности ответвления, одинаковый порядок на обоих шаблонах. Цвет/штриховка на экране справочные; в DXF различение по именам слоёв.

## Геометрическая модель и ограничения

Ось основной трубы — X. Ось ответвления u=(cos α,0,sin α) проходит через (0,e,0). При φ от 0 до 2π, радиусе r=d/2 и R=D/2:

```
y = e + r sin φ
z = sqrt(R² − y²)
t = (z + r cos φ cos α) / sin α
x = t cos α + r cos φ sin α
```

Берётся только ближняя (z ≥ 0) ветвь пересечения. Для замкнутой врезки с обеими справочными поверхностями требуется `abs(e)+r < R−T−0.001 мм`. Поэтому равные диаметры, касания, частичные/разомкнутые врезки и большие смещения отклоняются. Произвольное смещение осей из полного ТЗ в 0.1 не реализовано; e — кратчайшее расстояние между осями, перенос вдоль X не меняет форму.

Ответвление разворачивается как `(rφ, L−t−g)`, где `L=max(t)+50 мм` — фиксированная вспомогательная плоскость, а g — единый **осевой** отступ. Сторона с большими координатами t сохраняется. Начало по длине условное, общая длина заготовки не задаётся. При g>0 рез поднимается вдоль u, поэтому нормальное расстояние до основной трубы меняется по окружности. Это не постоянный нормальный сварочный зазор. Отверстие основной трубы при g не расширяется.

Отверстие: `(x, R atan2(y,z))`; шов развёртки находится с обратной стороны трубы. Справочная линия ответвления рассчитывается для r−t_wall и проецируется по той же φ на наружную развёртку; линия основной стенки рассчитывается для R−T и проецируется по углу на наружную поверхность. Это учёт двух поверхностей стенки для сравнения кромок, **не** развёртка фаски или готовая траектория реза через толщину. Внутренние линии не использовать как дополнительные линии реза.

Контуры экспортируются 1440 прямыми сегментами. Уравнения пересечения аналитические, но полилинии дискретные; гарантированного допуска для всего диапазона размеров нет. Почти касательные варианты могут иметь большую погрешность интерполяции. Проверка уравнений и масштаба не заменяет производственную верификацию. До изготовления нужна проверка геометрии, пробный бумажный шаблон и контроль на образце.

## Отложено

Постоянный зазор по нормали, фаски и разделка шва, компенсация инструмента/керфа, нейтральный слой, все виды пересечения и касаний, адаптивная дискретизация с заданным допуском, полноценные размерные цепочки и подписи меток, перетаскивание труб мышью, вычитание отверстия в 3D, сохранение проектов, раскладка на листы, подпись Developer ID и notarization, Intel/universal проверка.

## Проверки

```sh
swift test --disable-sandbox
```

Тесты проверяют остатки уравнений обоих цилиндров на углах 30/60/90° и смещениях ±15 мм, известное решение на 90°, развёрнутую окружность, валидацию, поверхности стенок, действие зазора, согласованность выборок, размер MediaBox PDF, DXF мм и переключение слоёв. Это геометрические и экспортные проверки, не сертификация технологии сварки.

Для генерации двух демонстрационных PDF/DXF без окна:

```sh
.build/release/PipeCut --export-samples /absolute/path/to/samples
```
