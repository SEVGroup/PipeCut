# Проверка 0.1

22 октября 2026, macOS, Apple Silicon arm64, Xcode 27.1 (27A9275), Swift package macOS 14 minimum.

- `swift test --disable-sandbox`: 6 XCTest, 0 failures; Swift Testing сообщает 0 собственных тестов, так как используются XCTest.
- `swift build --disable-sandbox -c release`: выполнено на реальном macOS SDK. Создание dSYM потребовало исполнения вне песочницы рабочего окружения.
- .app собран, подписан ad-hoc. GUI запущен и осмотрен через macOS UI automation. Исправлена невидимость линий предпросмотра на белом холсте в тёмной теме.
- Оба демонстрационных PDF созданы тем же экспортёром приложения, отрисованы Poppler и просмотрены. Проверка MediaBox входит в XCTest. Габариты страницы определяются выбранными слоями; масштаб геометрии не меняется.
- DXF экспорт проверен на объявление мм, завершение файла и переключение слоёв. Импорт в сторонний CAD и реальная плоттерная печать не проверялись.
- Производственные допуски, сварочный процесс, Intel и другие версии macOS не проверены. Полного UI-регрессионного покрытия нет.

## Dark Workshop — обновление интерфейса

- Нативная release-сборка обновлённого SwiftUI/SceneKit интерфейса прошла на том же macOS/arm64 окружении.
- Повторно выполнены 6 XCTest с нулём ошибок. Математическое ядро и экспортёры не изменялись.
- Вручную через macOS UI automation проверены ввод угла 45°, отклонение смещения 80 мм с отключением экспорта, сброс, смена вида спереди/сверху, включение и выключение линий, меню экспорта и сохранение DXF.
- Обе развёртки видны одновременно. В реальном окне проверены контраст, свет, компоновка и кнопки экспорта; это рабочий интерфейс, не изображение макета.
- 3D обновлён: полые стенки, торцы, оранжевая кромка, сетка, ортографические виды и вписывание модели. Сетка — декоративная в нормированных координатах, её шаг не является шкалой в мм.
- GUI-проверка выборочная, автоматизированного UI regression suite нет. Ограничения математической модели, точности и подписи приложения прежние.
